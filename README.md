# Student Management System

## Project Overview
A console-based Student Management System developed using Core Java to manage student records.

## Technologies Used
- Core Java
- Eclipse IDE
- ArrayList
- Scanner
- Iterator

## Features
- Add Student
- View All Students
- Search Student
- Update Student Details
- Delete Student
- Exit

## Concepts Used
- Classes and Objects
- Constructors
- Object-Oriented Programming
- Java Collections Framework

## How to Run
1. Download the project.
2. Import it into Eclipse IDE.
3. Open StudentManagementSystem.java.
4. Run as Java Application.
